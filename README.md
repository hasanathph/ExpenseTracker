# Expense Tracker

Expense Tracker is a web-based application that helps users manage their personal finances by tracking income and expenses, viewing transaction history, and monitoring monthly spending.

## Features

### User Module
- User Registration and Login
- Secure User Authentication
- User-wise Transaction Management
- Logout Functionality

### Transaction Management
- Add Income and Expenses
- Edit Transactions
- Delete Transactions
- Search and Filter Transactions
- View Transaction History

### Dashboard
- Total Transactions Summary
- Income and Expense Overview
- Expense Breakdown by Category
- Monthly Expense Tracker
- Monthly Spending Summary

## Technologies Used

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Tools:** VS Code, Git, GitHub

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/hasanathph/ExpenseTracker.git
   ```

2. Navigate to the backend folder:

   ```bash
   cd ExpenseTracker/backend
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Create a `.env` file inside the backend folder and configure your MongoDB connection string and required environment variables.

5. Start the backend server:

   ```bash
   node server.js
   ```

6. Open `index.html` using Live Server.

## Project Purpose

This project was developed to practice full-stack web development, REST API integration, database operations, and user authentication.
